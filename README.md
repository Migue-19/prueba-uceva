### GitHub
# que es github
 es una plataforma en la nube que permite almacenar, gestionar y colaborar en proyectos de software utilizando Git , un sistema de control de versiones. Es ampliamente utilizado por desarrolladores para trabajar en equipo, hacer seguimiento de cambios en el código y contribuir a proyectos de código abierto.

Características principales de GitHub:
Repositorio remoto : Puedes alojar proyectos y acceder a ellos desde cualquier lugar.
Control de versiones : Permite rastrear cambios en el código y revertir versiones anteriores si es necesario.
Colaboración : Facilitar el trabajo en equipo mediante pull request , issues y sucursales .
Integraciones y automatización : Compatible con CI/CD, GitHub Actions y muchas herramientas de desarrollo.
